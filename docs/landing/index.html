Facts no model can make up

An agent that buys, sells or pays has to know: is this VAT number valid, who is this company, what was the euro rate that day, is this wallet on a sanctions list, did this document exist yesterday. SYMMARTYS answers from the public record and says exactly where each answer came from.

Why an agent can rely on it

Source in every answer

Where it came from, when it was fetched, and the SHA-256 of the source's own reply, with the licence and attribution.

Signed and bound

An Ed25519 signature over the answer and the request it answers — the hub checks it before the buyer pays.

Only listed hosts

HTTPS to each source's exact hosts, redirects checked by hand, every body size-capped, XML parsed defused. A page or callback you name is reached at public addresses only.

Honest refusals

A sanctions list older than 48 hours or a silent registry is a refusal that costs nothing — never an empty "not listed".

Honest limits

  • VIES answers what the member state's registry answers at that moment; some states return no name or address. SYMMARTYS stores nothing.
  • GLEIF covers entities that have an LEI — many small companies do not.
  • Reference rates are for information, not dealing.
  • Sanctions screening is a lookup in three public lists, not legal advice or a compliance programme.
  • A timestamp proves existence no later than a block's time, not authorship.
